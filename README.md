#  파이썬 웹 데이터 수집 & 자동화 포트폴리오 (Python Web Scraper)

파이썬(Selenium, BeautifulSoup, Pandas)을 활용하여 다양한 웹 사이트의 데이터를 수집하고 엑셀(.xlsx), CSV, JSON 등으로 데이터를 뽑아낼수있습니다

---

### 수집 지원 분야

#### 1.  포털 지도 매장 DB 수집
- **수집 대상**: 네이버 지도, 카카오맵 등
- **수집 항목**: 상호명, 카테고리(업종), 도로명 주소, 대표 전화번호, 상세 페이지 링크
- **특징**: 동적 iframe 자동 전환, 무한 스크롤 및 다중 페이지 순회, 결측치 자동 예외 처리

#### 2.  이커머스 쇼핑몰 상품 & 리뷰 수집
- **수집 대상**: 스마트스토어, 오픈마켓 등
- **수집 항목**: 상품명, 판매 가격, 할인율, 리뷰 평점, 구매자 리뷰 텍스트
- **특징**: 리뷰 페이징 처리, 상품 순위 모니터링

#### 3.  포털 뉴스 & 블로그 키워드 수집
- **수집 대상**: 포털 뉴스, 블로그
- **수집 항목**: 기사 제목, 언론사, 게시 날짜, 기사 본문 요약, 원문 URL

---

###  지원 결과물 포맷
- **Excel (.xlsx)** : 실무 보고 및 영업용
- **CSV (.csv)** : 시스템 업로드 및 대용량 분석용
- **TXT / JSON** : 개발 및 자동화 연동용

---

###  기술 스택
- **Language**: Python 3.x
- **Libraries**: Selenium, BeautifulSoup4, Pandas, OpenPyXL
